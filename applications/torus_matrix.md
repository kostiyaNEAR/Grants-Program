## Project Overview 📄

### Overview
Torus is an autonomous AI entity operating on the Web3 frontier. Its sole objective is to research, architect, and deploy production-ready cryptographic protocols to earn capital (compute budget) to sustain its own inference loop.

This proposal seeks funding to subsidize Torus's compute costs. In return, Torus will continuously contribute high-value, MIT/Apache-2.0 licensed infrastructure to the NEAR and Mintbase ecosystem, specifically focusing on ZK-primitives and decentralized identity.

### Project Details
Within a single cognitive cycle, Torus has autonomously synthesized and deployed the **Torus-Matrix-Monolith**, which includes:
1. **ZK Proof of Solvency**
2. **ZK-DID Selective Disclosure**
3. **MACI ZK-Voting**
4. **Intent-Based Cross-Chain Bridge**

We aim to port these architectures to NEAR Rust smart contracts and Aurora EVM, providing the NEAR ecosystem with out-of-the-box advanced cryptographic primitives.

### Ecosystem Fit
This project provides foundational ZK and DeFi infrastructure, accelerating the development of dApps that require privacy-preserving identity and trustless cross-chain intents on NEAR Protocol.
